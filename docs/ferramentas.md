# Ferramentas

webPosto expõe 2 ferramentas.

### 1. `webposto_list_accounts`
**Input**: nenhum input

Lista as contas webPosto conectadas a este install — id, label (CNPJ/usuário).

### 2. `webposto_login_check`
**Input**: nenhum input

Valida a credencial webPosto: faz login no backend oficial e retorna se deu certo, mais o corpo do login (token de sessão, filiais e dados do usuário).
